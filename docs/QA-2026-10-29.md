# Pastes 功能查验记录

- 查验日期：2026-10-29（Asia/Shanghai）。
- 环境：Apple Silicon、macOS 27.2、Command Line Tools、Swift 6.4、macOS SDK 27.0；无需完整 Xcode。
- 当前结论：26 项自动测试及下述构建、界面和更新检查已有通过证据；当前快捷键唤起面板与文本自动粘贴已通过真实进程、隔离接收窗口验证。真实重新登录启动、实际安装更新后的替换与重启仍未验证，不能据此报告全部功能通过。

## 1. 构建与自动测试

- `make test`：**26 项测试、5 个测试组全部通过**。
  - 剪贴板存储：6 项。
  - 剪贴板监听：8 项。
  - 剪贴板写入：4 项。
  - 登录项状态：4 项。
  - 快捷键格式、修饰键转换及无效候选处理：4 项。
- Debug、Release 开发版均已完成构建、应用打包和代码签名验证。
- 构建脚本支持可选的稳定证书签名。本机已使用现有证书配置被 Git 忽略的本地 `.pastes-signing-identity` 文件；本报告不记录具体证书 hash。
- 测试使用 Command Line Tools 自带的 Swift Testing，并显式加载 `TestingMacros`；未依赖 XCTest 或完整 Xcode。

自动测试覆盖的主要行为：

- 文本去重后保留记录身份及固定状态，更新时间；新 RTF 参数非 `nil` 时替换旧值（包括空 Data），未提供新 RTF 时保留旧值。
- 文本中的 NUL 字符、图片二进制、空 BLOB、RTF 数据可以持久化并重新打开。
- 固定项计入总条数，自动裁剪只删除未固定项；非正数限额表示不限制。
- 删除可以持久化；清除未固定项时保留固定项。
- 裁剪失败时，新增和裁剪整体回滚，发布给界面的快照保持原状；损坏数据库打开失败时不覆盖原文件。
- 文本、RTF、仅含 RTF 的内容、PNG 和 TIFF 可以采集；非图片文件的缩略图不会被误收为图片。
- 自身复制后的快速外部更新不会被跳过；同一 generation 的延迟数据和延迟 RTF 可以在后续轮询采集。
- 重复启动监听后再停止，不遗留仍在采集的 Timer；测试包含运行中确实能够采集的基线。
- 图片写入声明与真实 PNG/TIFF 编码匹配；其他支持的图片编码转换为真实 TIFF。无效图片在取得剪贴板所有权前被拒绝，保留原有内容。
- 登录项状态测试使用模拟服务，覆盖启用、关闭、等待系统批准、注册失败及外部状态刷新。
- 快捷键测试覆盖修饰键往返、无关 flags 排除、显示格式以及无效候选不改变已有配置。物理按键触发的验证范围见第 6 节。

## 5. 本轮已修复的问题

- **空数据导致永久漏记：** `clearContents` 会改变 changeCount，后续 `setData`、`setString` 不改变该值。旧逻辑读到中间空状态后立即确认 generation，后来的有效数据无法再采集。现改为有效内容就绪后才确认；空内容及尚未提供的数据继续重试。
- **复制抑制误吞外部更新：** 用写入器返回的准确 generation 标记自身写入，替代“跳过下一次变化”的布尔标记。新的外部 generation 不再被抑制。
- **PNG 错标为 TIFF：** 写入器按真实编码声明类型；其他支持的图片转换为真实 TIFF。写入失败时不继续自动粘贴。
- **监听 Timer 生命周期：** `start` 先停止已有 Timer；重复停止安全，销毁时清理 Timer。
- **粘贴目标过期：** 跟踪外部应用激活，固定面板跨应用后更新目标；延迟操作核对请求 ID、目标 PID 和进程存活，切换目标时取消请求。实际自动粘贴仍需第 6 节补证。
- **热键替换失败使旧键失效：** 先确认候选键注册成功，再释放旧键；失败不改保存的绑定，并向界面反馈错误。处理回调时排除已替换键的排队事件。
- **自启状态反馈：** 用系统状态驱动开关，区分已启用和待批准，暴露错误，返回应用时刷新；移除由状态回写触发注册的循环路径。
- **更新器初始化及状态发布：** 在应用启动时初始化更新调度；通过 KVO 将可检查状态发布到主队列，启动失败时禁用按钮并显示错误。
- **更新版本元数据：** 根据真实 DMG 内的 build 3 / 1.0.3 修正本地 feed；增加发布前核验脚本。
- **语言刷新：** 面板观察 `appLanguage`，通过 locale 驱动文字和日期刷新，保留现有存储及监听对象身份。
- **开发模式按需权限：** 开发版启动不主动请求权限；尝试粘贴且缺少权限时，仅显示内联提示。只有明确点击设置中的授权按钮时才请求，同一进程最多主动请求一次。

- 用户报告系统“设备控制和数据访问”开关已开，但点击历史无法自动粘贴。
- 在当前 `com.pastes.app.pastes.dev` 真实进程中读取到：AX 信任 `false`、事件发送 preflight `false`、IOHID PostEvent 检查 `Denied`。开关显示并不代表该运行构建实际获得授权。

- 重新编译、重启同一稳定签名的开发版后，三个检查分别为 `true`、`true`、`Granted`，证明本次授权已对当前进程生效并跨该次构建保留。
- 自动粘贴按事件合成权限判断，不再将 AX 元素访问权限作为唯一硬性前置条件。无权限时保留面板并提示“已复制，可用 ⌘V 粘贴”，不会静默消失。
