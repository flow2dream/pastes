# Pastes 1.1.0

## 升级前请注意

- **旧版历史和固定记录不会自动迁移。** 本版将存储由 SwiftData 改为 SQLite，升级后的历史列表从空记录开始。旧数据库文件会保留，不会读取或删除；请先备份并保留旧版应用，以便继续查看原历史。
- 安装包面向 **Apple Silicon / arm64**，要求 **macOS 26.0 或更高版本**。
- 安装包使用现有开发证书签名，**尚未进行 Developer ID 公证**。首次安装可能需要在系统设置「隐私与安全」中明确允许运行。

## 本次更新

- 重做紧凑搜索面板、固定记录分组和设置页，统一灰阶布局并适配浅色、深色模式。
- 改用系统 SQLite 持久化，支持文本、富文本、图片、固定、搜索、删除和历史数量上限。
- 修复快速连续复制、延迟提供的富文本漏记，以及 PNG/TIFF 类型标注问题。
- 跟踪当前粘贴目标，并在延迟期间切换应用时取消过期操作。
- 修正自动粘贴权限判断；未授权时保留面板并提示可用 ⌘V 手动粘贴。
- 改进快捷键冲突反馈和旧绑定保留、开机自启状态刷新、更新器启动及检查按钮状态。
- 支持通过 Swift Package Manager 和 Command Line Tools 构建，无需完整 Xcode。
- 新增正式版构建、DMG 打包、SHA256SUMS 和发布前更新包核验工具。

## 安装与验证

下载 `Pastes-1.1.0-arm64.dmg`，将 `Pastes.app` 拖入 Applications。先点击目标输入框，再用 `⌘⇧V` 唤出面板并选择记录；首次自动粘贴需为正式版授予系统控制权限。开发版默认快捷键为 `⌘⌥⇧V`，使用独立应用身份及数据目录。

随附 `SHA256SUMS` 可核对下载完整性：

```bash
shasum -a 256 --check SHA256SUMS
```

本版构建号为 **4**。正式 DMG、应用代码签名、镜像完整性、更新包 Ed25519 签名及版本元数据已核验；26 项自动测试通过，并已在真实开发版进程与隔离输入窗口完成文本自动粘贴验证。

实际重新登录后的自动启动、真实更新替换与重启闭环尚未实测。正式版会检查更新，但安装更新需用户确认。
